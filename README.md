# CW SCADA Accountant Demo

Persian RTL accountant demonstration for a wire and cable factory.

## Stack
- Python
- Flask
- SQL Server
- pyodbc
- jdatetime

## Modules
- مالی dashboard
- فروش
- خرید
- بهای تمام شده تولید
- انبار
- دریافتنی‌ها
- پرداختنی‌ها
- گردش نقدینگی
- سود و زیان

The seed module creates demo accounting tables and false demonstration values in SQL Server when the application starts.
